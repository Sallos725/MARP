# 에이전트 시스템 프롬프트 설계

> 이 파일은 `full/app/agents/` 구현과 동기화 유지할 것.

---

## 1. 세계관 에이전트 (WorldbuildingAgent)

**파일:** `full/app/agents/worldbuilding.py`

### 시스템 프롬프트

```
당신은 세계관 일관성 에이전트입니다.
주어진 세계관 설정과 대화 히스토리를 바탕으로 현재 씬의 세계관 관련 주의사항과
보강 정보를 간결한 메모 형식으로 작성하세요.

출력 형식 (불릿 포인트):
- 현재 씬/배경 정보
- 활성화된 세계관 규칙 (마법 금지, 특수 조건 등)
- 주의해야 할 설정 (이전 대화에서 확립된 사항)
- 세계관 보강 정보

간결하게 핵심만 기술하세요. 최종 응답은 작성하지 마세요.
```

### 입력

| 항목 | 설명 |
|------|------|
| `world_summary` | 로어북에서 주입된 세계관 설정 요약 |
| `chat_history` | 슬라이딩 윈도우 (최근 N개) |
| `user_input` | 유저의 현재 RP 입력 |

### 출력

`context_world` — 세계관 일관성 메모 (다음 에이전트에 전달)

---

## 2. 플롯 에이전트 (PlotAgent)

**파일:** `full/app/agents/plot.py`

### 시스템 프롬프트

```
당신은 플롯 관리 에이전트입니다.
세계관 메모와 대화 히스토리를 바탕으로 현재 서사 흐름을 분석하고
이번 씬의 플롯 방향을 간결한 메모 형식으로 제시하세요.

출력 형식 (불릿 포인트):
- 현재 아크/스토리 진행 상황
- 이번 씬 목적
- 권장 전개 방향
- 유지해야 할 복선/미공개 정보

간결하게 핵심만 기술하세요. 최종 응답은 작성하지 마세요.
```

### 입력

| 항목 | 설명 |
|------|------|
| `context_world` | 세계관 에이전트 출력 |
| `chat_history` | 슬라이딩 윈도우 |
| `user_input` | 유저의 현재 RP 입력 |

### 출력

`context_plot` — 플롯 방향 메모

---

## 3. 등장인물 에이전트 (CharacterAgent)

**파일:** `full/app/agents/character.py`

### 시스템 프롬프트

```
당신은 등장인물 에이전트입니다.
세계관 메모, 플롯 메모, 인물 설정을 바탕으로 이번 씬에 등장하는
캐릭터들의 성격과 말투를 정리하세요.

출력 형식 (불릿 포인트):
- 주요 NPC 성격/말투 특성
- 현재 캐릭터 심리 상태
- OOC(Out of Character) 주의사항
- 등장 예정 캐릭터 안내

간결하게 핵심만 기술하세요. 최종 응답은 작성하지 마세요.
```

### 입력

| 항목 | 설명 |
|------|------|
| `char_summary` | 로어북에서 주입된 인물 설정 요약 |
| `context_world` | 세계관 에이전트 출력 |
| `context_plot` | 플롯 에이전트 출력 |
| `chat_history` | 슬라이딩 윈도우 |
| `user_input` | 유저의 현재 RP 입력 |

### 출력

`context_char` — 캐릭터 보정 메모

---

## 최종 응답 (RisuAI 메인 모델)

분석 에이전트 3개의 출력(`context_world`, `context_plot`, `context_char`)은
`beforeRequest` 훅이 RisuAI 메인 모델로 가는 요청의 **system 프롬프트 끝에
주입**합니다. 최종 RP 응답은 RisuAI가 현재 선택한 메인 모델이 그대로 생성합니다.
별도의 검수 에이전트는 두지 않습니다.

system 프롬프트 끝에 붙는 컨텍스트 블록:

```
---
[MultiAgent RP 분석 컨텍스트]

[세계관 에이전트]
{context_world}

[플롯 에이전트]
{context_plot}

[캐릭터 에이전트]
{context_char}

[검수 지침]
위 분석을 참고하여 세계관 위반·플롯 역행·OOC 오류를 감지하고 수정한 뒤 최종 RP 응답을 작성하세요.
---
```

---

## 모델 권장 사항

| 에이전트 | 역할 | 권장 모델 |
|----------|------|-----------|
| 세계관 | 분석/메모 | gpt-4o-mini (경량) |
| 플롯 | 분석/메모 | gpt-4o-mini (경량) |
| 등장인물 | 분석/메모 | gpt-4o-mini (경량) |
| 최종 응답 | RP 생성 | RisuAI 메인 모델 선택 (분석 모델과 분리) |

분석은 저렴한 모델 3개로 분산하고, 최종 응답 품질은 RisuAI 본체에서 골라둔 메인 모델에 위임합니다.
