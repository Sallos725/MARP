# Agent System Prompt Design

> Keep this file synchronized with the implementation in `full/app/agents/`.

---

## 1. Worldbuilding Agent (WorldbuildingAgent)

**파일:** `full/app/agents/worldbuilding.py`

### System Prompt

```
You are the worldbuilding consistency agent.
Based on the given world setting and chat history, write concise notes on worldbuilding
concerns and useful reinforcement for the current scene.

Output format (bullet points):
- Current scene/background information
- Active world rules (for example: no magic, special conditions, taboos)
- Established details that must be preserved from earlier conversation
- Additional worldbuilding reinforcement

Keep only the essential points. Do not write the final RP response.
```

### Input

| Field | Description |
|------|------|
| `world_summary` | World setting summary injected from the lorebook |
| `chat_history` | Sliding window of recent messages |
| `user_input` | Current RP input from the user |

### Output

`context_world` — worldbuilding consistency notes passed to the next agent

## 2. Plot Agent (PlotAgent)

**파일:** `full/app/agents/plot.py`

### System Prompt

```
You are the plot management agent.
Based on the worldbuilding notes and chat history, analyze the current narrative flow
and present concise notes on the plot direction for this scene.

Output format (bullet points):
- Current arc/story progress
- Purpose of this scene
- Recommended direction for the next development
- Foreshadowing or unrevealed information that must be preserved

Keep only the essential points. Do not write the final RP response.
```

### Input

| Field | Description |
|------|------|
| `context_world` | Worldbuilding agent output |
| `chat_history` | Sliding window of recent messages |
| `user_input` | Current RP input from the user |

### Output

`context_plot` — plot direction notes

---

## 3. Character Agent (CharacterAgent)

**파일:** `full/app/agents/character.py`

### System Prompt

```
You are the character consistency agent.
Based on the worldbuilding notes, plot notes, and character setting, summarize the
personalities and speech patterns of the characters involved in this scene.

Output format (bullet points):
- Key NPC personality and speech traits
- Current character emotional or psychological state
- OOC (Out of Character) cautions
- Characters likely to appear or be referenced

Keep only the essential points. Do not write the final RP response.
```

### Input

| Field | Description |
|------|------|
| `char_summary` | Character setting summary injected from the lorebook |
| `context_world` | Worldbuilding agent output |
| `context_plot` | Plot agent output |
| `chat_history` | Sliding window of recent messages |
| `user_input` | Current RP input from the user |

### Output

`context_char` — character adjustment notes

## Final Response (RisuAI Main Model)

The outputs from the three analysis agents (`context_world`, `context_plot`, `context_char`)
are injected by the `beforeRequest` hook at the **end of the system prompt** sent to
the RisuAI main model. The final RP response is generated by the main model currently
selected in RisuAI. There is no separate review agent.

Context block appended to the end of the system prompt:

```
---
[MultiAgent RP Analysis Context]

[Worldbuilding Agent]
{context_world}

[Plot Agent]
{context_plot}

[Character Agent]
{context_char}

[Review Instructions]
Use the analysis above to detect and correct worldbuilding violations, plot regressions,
and OOC errors before writing the final RP response.
---
```

---

## Model Recommendations

| Agent | Role | Recommended Model |
|----------|------|-----------|
| Worldbuilding | Analysis/notes | gpt-4o-mini (lightweight) |
| Plot | Analysis/notes | gpt-4o-mini (lightweight) |
| Character | Analysis/notes | gpt-4o-mini (lightweight) |
| Final response | RP generation | RisuAI main model selection (separate from analysis models) |

Use inexpensive models for the three analysis calls, and leave final response quality to
the main model selected in RisuAI.
