# 워터폴·연결 테스트·호출 기록 사용법

[처음으로](../README.md) · [설정 안내](SETTINGS.md) · [PDF 안내](PDF.md)

채팅 입력창 왼쪽 햄버거 메뉴에서 **MARP Lite** 또는 **MARP Full**을 선택해 화면을 엽니다. v0.9.2부터 캐릭터 목록 쪽 메뉴의 MARP 항목을 이 위치로 옮겼습니다. RisuAI의 MARP 설정에서도 같은 화면을 열 수 있습니다. 좁은 화면에서는 위쪽 탭을 좌우로 스크롤할 수 있습니다.

## 가장 빠른 확인 순서

1. **연결 테스트**에서 전체 또는 원하는 에이전트를 검사합니다.
2. **진단**에서 텍스트 분석 테스트를 실행해 실제 응답이 나오는지 확인합니다. 내장 PDF를 사용할 때는 PDF 분석 테스트도 실행합니다.
3. **워터폴**에서 단계별 시간과 성공·실패 상태를 확인합니다.
4. **호출 기록**에서 이전 실행을 펼쳐 모델·사용량·오류·결과 미리보기를 비교합니다.

## 연결 테스트와 분석 테스트의 차이

| 기능 | 무엇을 확인하나요? | LLM 응답 생성 |
| --- | --- | --- |
| 전체·개별 연결 테스트 | 모델 조회 API 연결과 인증. Vertex는 서비스 계정 OAuth 인증 | 없음 |
| Full 서버 상태 확인 | MARP 서버 접근과 설정 준비 상태 | 없음 |
| 텍스트 분석 테스트 | 합성 자료에 대한 실제 분석 응답 | 있음 |
| PDF 분석 테스트 | 내장 PDF 처리와 실제 분석 응답. 조건에 따라 텍스트로 복귀 가능 | 있음 |

연결 성공만으로 특정 모델의 응답 생성 권한이나 PDF 지원이 확인되지는 않습니다. 모델 조회 경로를 지원하지 않는 프록시는 연결 검사에 실패해도 분석 요청은 처리할 수 있습니다. 이 경우 진단 탭에서 실제 분석을 확인합니다.

Lite는 **현재 편집값**을 사용하므로 저장하기 전에 검사할 수 있습니다. Full은 **입력한 서버 URL에 저장된 공급자 설정**을 사용하므로 공급자 설정을 수정했다면 먼저 저장합니다. 전체 연결 검사에서 OFF인 에이전트는 건너뜁니다. 개별 OFF 에이전트는 켠 뒤 검사하세요.

## 워터폴 읽기

세계관 분석이 먼저 실행되고 플롯·등장인물 분석이 뒤에서 병렬로 실행됩니다. 막대의 시작 위치는 해당 단계가 시작한 시점, 길이는 소요 시간입니다. 상태가 문자로 함께 표시되므로 색상만으로 판단할 필요가 없습니다.

v0.9.1 Lite와 Full 서버는 시작 시각을 계측합니다. 구버전 Full 서버가 시작 시각을 보내지 않으면 기존 지연 시간과 실행 순서로 위치를 추정하고 화면에 **추정**이라고 표시합니다. 전체 시간에는 준비 작업이 포함되고 Full은 서버 왕복·대기 시간도 포함될 수 있습니다. 단계별 시간을 더한 값과 전체 시간이 같을 필요는 없습니다.

에이전트 상세를 펼치면 모델, 오류, 공급자 사용량, PDF 처리 정보와 결과 미리보기가 표시됩니다. `usage`는 공급자가 반환한 실제 사용량이며 `estimated_source_tokens`는 PDF로 처리할 자료의 토큰 추정치입니다. 화면은 고정 단가로 비용을 추정하지 않습니다.

## 호출 기록과 보관 범위

- 대화 분석, 연결 테스트, 텍스트/PDF 테스트를 **최근 50건**까지 기록합니다.
- 종류별 또는 실패 포함 필터를 사용하고, 기록을 펼쳐 상세 정보를 확인합니다.
- 분석 결과 미리보기는 **에이전트당 앞 2,000자**까지 보관하며, 잘린 결과임을 표시합니다. 대화에 주입하는 실제 분석 결과는 이 제한으로 잘리지 않습니다.
- **기록 JSON 내보내기**는 현재 목록에 불러온 전체 기록을 저장합니다. 화면 필터와 관계없이 미리보기도 포함합니다.
- **기록 비우기**는 현재 세션의 기록을 지웁니다. 설정이나 대화는 삭제하지 않습니다.
- 기록은 현재 플러그인 세션의 메모리에만 보관합니다. 화면을 닫았다 열어도 유지되지만 플러그인 재로드·해제 시 초기화됩니다. 다른 기기나 재시작 이전 기록을 가져오지는 않습니다.
- 입력 대화·설정 객체를 기록하지 않습니다. 분석·테스트 결과에는 대화에서 파생된 내용이 있을 수 있으므로 공유할 때 미리보기를 확인합니다.

목록과 워터폴은 탭에 들어가거나 **새로고침**을 누를 때 갱신됩니다. 자동 폴링·자동 저장은 없습니다. 진행 중인 테스트 결과는 완료 후 기록되며, 다른 탭으로 이동해도 그 화면을 덮어쓰지 않습니다.

## 상태 표시

| 표시 | 의미 |
| --- | --- |
| 분석 주입 완료 | 사용 가능한 분석 메모를 메인 요청에 넣었습니다. Lenient에서는 일부 에이전트가 실패할 수 있으므로 상세도 확인합니다. |
| 실패 · 미주입 | 분석 실패 또는 Strict 설정으로 주입을 중단했습니다. |
| 결과 없음 · 미주입 | 주입할 결과가 없습니다. 전체 OFF 상태도 여기에 해당합니다. |
| 일부 테스트 실패 | 성공한 항목과 실패한 항목이 함께 있습니다. |
| 테스트 대상 또는 결과 없음 | 전체 OFF이거나 표시할 결과가 없습니다. |
| 정보 없음 | 서버 응답에 단계 진단이 없거나 단계 시작 전 실패했습니다. |

PDF Pod가 훅 오류를 흡수하면 Strict가 메인 모델 호출까지 막는다고 보장할 수 없습니다. 화면의 미주입은 MARP 분석 메모의 주입 여부를 뜻합니다.
